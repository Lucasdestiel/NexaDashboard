# ✦ Nexa — Freelance Finance Dashboard

**Seu trabalho, seus resultados, tudo em um só lugar.**

O Nexa é um dashboard financeiro desenvolvido para freelancers que desejam acompanhar seus ganhos, organizar receitas e visualizar seu desempenho financeiro em diferentes moedas.

O projeto apresenta uma interface moderna e intuitiva, com indicadores financeiros, gráficos interativos e gerenciamento de receitas em Real (BRL) e Dólar (USD).

## ✨ Funcionalidades

- **Visão financeira:** acompanhamento do faturamento total, receitas recebidas e valores pendentes.
- **Multi-moedas:** visualização de receitas em BRL e USD.
- **Gráficos interativos:** representação visual do faturamento por período.
- **Filtros dinâmicos:** consulta de dados dos últimos 7, 30 e 90 dias ou histórico completo.
- **Gestão de clientes:** tabela com projetos, valores e status de pagamento.
- **Registro de receitas:** formulário para adicionar novos trabalhos.
- **Dashboard responsivo:** interface adaptada para desktop, tablet e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura da aplicação |
| CSS3 | Layout, responsividade e identidade visual |
| JavaScript | Lógica, filtros e interações |
| Canvas API | Renderização dos gráficos |

## 🎨 Design

O Nexa utiliza uma identidade visual baseada em uma interface dark, com tons de roxo, verde e azul para destacar informações financeiras.

Principais características:
- Interface minimalista.
- Navegação lateral.
- Cards com indicadores financeiros.
- Gráficos e elementos visuais.
- Layout Mobile First.


## 📌 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar e demonstrar conhecimentos em desenvolvimento Frontend, manipulação de dados com JavaScript, construção de interfaces responsivas e criação de dashboards administrativos.
